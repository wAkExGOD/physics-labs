## Повторить расчёты

Требуется Python 3.10 или новее. В терминале из каталога `lab2`:

```powershell
python -m pip install -r requirements.txt
python lab2.py
```

Скрипт можно запускать из любого каталога: пути определяются по расположению
`lab2.py`. Выходные файлы обновляются автоматически; Excel не изменяется.
Если Python установлен под другим именем, замените `python` на путь к нему.

Для первоначальной обработки в этой среде дополнительные библиотеки установлены
локально в скрытую `.tools/`. Если они не установлены в вашем окружении,
существующую локальную копию можно использовать из каталога `lab2`:

```powershell
$env:PYTHONPATH = (Resolve-Path .tools).Path
python lab2.py
```

## Собрать PDF

Нужны XeLaTeX (например, MiKTeX или TeX Live), Times New Roman и Consolas.
Основной текст — Times New Roman, 12 пт, интервал 1,5; код — Consolas.
В каталоге `lab2` после запуска расчётов:

```powershell
.\build.ps1
```

Скрипт выполняет два прохода XeLaTeX для оглавления и перекрёстных ссылок,
проверяет успешность сборки и затем копирует PDF в `lab2.pdf`.
Его можно вызвать и из корня проекта: `.\lab2\build.ps1`.

Если редактор ранее собирал документ в каталог исходников, оставшиеся там
`lab2.aux`, `lab2.toc`, `lab2.out` могут перекрывать актуальные файлы из
`build/`: тогда оглавление будет пустым даже после двух проходов.
Скрипт предварительно переносит такие файлы в `build/previous-root/`.
В настройках LaTeX-расширения редактора также используйте каталог вывода `build`.
На Overleaf выберите компилятор XeLaTeX; при отсутствии лицензионного шрифта
Times New Roman потребуется добавить файлы шрифта в проект и настроить `fontspec`.

## Особенности данных и результата

В таблице 97 заполненных пар координат, а не 100. Шаг — 4 с, продолжительность —
384 с. Пустые координаты в последних трёх строках не заменяются нулями.
Используются все пары с лагами 1–9: время на графике — 4–36 с.

Масштаб в мкм/пиксель отсутствует. Значения MSD выражены в пиксель²,
коэффициент диффузии — в пиксель²/с. Свободная прямая даёт
`a ≈ 196,86`, `c ≈ 1031,87`, `R² ≈ 0,9819`, `D ≈ 49,21`;
модель через начало — `A ≈ 237,59`, `D₀ ≈ 59,40`.
В отчёте различаются приближённая линейность и строгое выполнение
формулы Эйнштейна: свободный сдвиг заметен, а надёжные доверительные
интервалы по коррелированным лаговым средним не оценивались.
