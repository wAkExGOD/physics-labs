# Лабораторная работа № 4 — волновая оптика

- `lab4.tex`, `lab4.pdf` — исходник и готовый отчёт.
- `lab4.py` — расчёты пяти заданий; задание 5 содержит четыре случая дифракции.
- `FAQ.md` — определения, физический смысл, применение и пояснение программы.
- `FAQ_SIMPLE.md` — объяснение каждого задания простыми словами, с примерами и фразами для устной сдачи.
- `figures/` — восемь рисунков в PDF и PNG.
- `results/` — CSV, `summary.json`, автоматически создаваемые LaTeX-вставки.
- `instructions.pdf` — условие и теория.
- `build/` — промежуточные файлы сборки и проверки.

## Расчёты

Из корня проекта:

```powershell
python -m pip install -r lab4/requirements.txt
python lab4/lab4.py
```

На macOS используйте `python3` или Python из активированного виртуального
окружения. Все пути считаются от `lab4.py`. Результаты обновляются,
исходный PDF не изменяется.

## Сборка PDF

Нужны XeLaTeX и Times New Roman. Из корня проекта на Windows:

```powershell
.\lab4\build.ps1
```

На macOS/Linux:

```bash
bash build_pdf.sh 4
```

Из каталога `lab4` также можно выполнить `bash build.sh`.
Полная установка описана в [MAC_SETUP.md](../MAC_SETUP.md).

## Принятые модели

Длина волны 550 нм, интенсивности относительные. Экран в 2 м,
расстояние между точечными источниками 0,20 мм, ширина щели 50 мкм,
радиус круглого отверстия 0,10 мм. Эти параметры подобраны для наглядных
картин; значения для сравнений указаны на графиках.

В плёнке толщиной 2 мкм принята система воздух–плёнка–воздух и два
равноамплитудных отражённых луча. Учтён относительный скачок фазы π;
коэффициенты Френеля и многократные отражения опущены. Показана
нормированная форма картины, а не коэффициент отражения. `n = 0.8` —
модельный случай сравнения.

Радиус Эйри рассчитывается через первый нуль J₁: множитель около 0,61
используется с радиусом отверстия, около 1,22 — с диаметром.
Для решётки центральный максимум нормирован к 1 делением на N²;
дифракционная огибающая отдельных узких щелей не учитывается.

Расхождения сеточных и аналитических результатов характеризуют
дискретизацию модели; они не являются погрешностями измерения.
