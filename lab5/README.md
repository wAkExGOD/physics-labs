# Лаба 5 — дифракция электронов

Локальное оконное приложение для всех трёх упражнений. Сеть и старое
`difraction.exe` для запуска не нужны.

## Установка и запуск

Из корня проекта:

```powershell
python -m pip install -r lab5/requirements.txt
python lab5/lab5.py
```

На Mac используйте Python из виртуального окружения; при необходимости
замените `python` на `python3`. Нужен Tkinter: проверить установку можно
командой `python -m tkinter` — появится небольшое тестовое окно.
Стандартный установщик Python с python.org включает поддержку Tk.
При отсутствии Tk установите Python с этой поддержкой; `pip install tkinter`
не является способом установки системной библиотеки Tk.

## Как выполнить задания

1. **Накопление.** На первой вкладке выберите 40 кВ, порцию 10, 1000 или
   10 000, нажмите «Новая серия», затем «Пуск / добавить». Повторите при
   60 и 120 кВ. «Сразу» завершает текущую порцию или добавляет новую без анимации.
2. **Статистика.** Выберите порцию 1000, шаг графика от 5 до 50.
   График показывает доли `k1/k` и `k2/k`; центральный пучок не входит в `k`.
   Таблица отдельно показывает и доли среди всех выпущенных электронов.
3. **Закон де Бройля.** На второй вкладке «Выполнить серию» рассчитывает
   30, 37, 47, 61, 83, 120 кВ, измеряет кольца 2 и 3 и строит график R(X).
4. **Структура.** На третьей вкладке «Измерить модельную серию» заполняет
   пять радиусов при 30 кВ. Их можно заменить своими измерениями и нажать
   «Вычислить d и индексы». Для кольца 4 второй порядок учитывается автоматически.
5. Вкладка «Как работать» содержит краткую инструкцию. Теория — в `FAQ.md`.

## Управление и сохранение

- Темп меняется сразу, без остановки и нового пуска.
- Пауза сохраняет точки и график; повторный пуск завершает текущую порцию.
- Масштаб ×1–×4 можно менять во время накопления: координаты не стираются.
- У каждого напряжения отдельная серия. Переключение останавливает анимацию,
  а возвращение к напряжению показывает сохранённые точки.
- Миллиметры берутся с осей графика, не с физической линейки на мониторе.
  Щелчок по электронограмме показывает радиус от центра.
- JSON сохраняет точки и состояние генератора: после загрузки можно точно продолжить серию.
- CSV сохраняет координаты и результаты вычислений; PNG — вид графиков.
- Seed применяется при «Новая серия». При добавлении генератор не переинициализируется.
- Точка и десятичная запятая принимаются; неверные/пустые значения не подменяются нулями.
- В таблицах и графиках нет ограничения на 20 шагов. Лимит одной серии — 1 млн электронов.

## Отчёт и файлы

- `lab5.py` — точка входа.
- `lab5_model.py` — формулы, генератор попаданий, измерение радиусов, индексы.
- `lab5_app.py` — интерфейс Tkinter и графики Matplotlib.
- `lab5_report.py` — серии, таблицы и рисунки отчёта.
- `lab5.tex`, `lab5.pdf` — исходник и готовый отчёт.
- `figures/` — четыре рисунка в PDF и PNG.
- `results/` — CSV, `summary.json`, вставки LaTeX и пример сохранённой серии `demo_40kV.json`.
- `tests/` — проверки формул, статистики и продолжения сохранённых серий.
- `build/` — служебные файлы и снимки тестового окна.
- `theory.pdf`, `tasks.pdf`, `app-controlling.pdf`, `app-example/` — исходные материалы.

Пересчитать всё без открытия окна и собрать отчёт на Windows:

```powershell
python lab5/lab5.py --generate
.\lab5\build.ps1
```

На Mac/Linux:

```bash
python lab5/lab5.py --generate
bash build_pdf.sh 5
```

Для сборки уже имеющихся результатов Python не нужен: достаточно XeLaTeX,
Times New Roman и Consolas. Установка описана в [MAC_SETUP.md](../MAC_SETUP.md).
Для другой воспроизводимой серии используйте `--seed 123`.

Проверка вычислительной части:

```powershell
python -m unittest discover -s lab5/tests -v
```

## Что является модельным предположением

Принята кинематическая малоугловая модель железа с параметром ячейки 2,87 Å
и расстоянием до экрана 757 мм. Все константы взяты в округлении tasks.pdf.
Длина волны релятивистская. Вероятности каналов и размытие колец заданы
явно, а не рассчитаны из потенциала реального кристалла.
Радиусы измеряются по координатам модельных попаданий в кольцевых областях.
Они не являются измерениями реального образца. Линейность R(X) проверяет
согласованность модели, а не независимо подтверждает уже заложенный в неё закон.

Перебор индексов ограничен S ≤ 200; для первых пяти колец достаточно S ≤ 10.
Масштаб ×4 — увеличение вида, а не изменение физических радиусов.
