# Лабораторная работа № 1: метод конечных разностей

- `lab1.py` — расчёты и графики трёх заданий с поясняющими комментариями.
- `lab1.tex`, `lab1.pdf` — исходник и отчёт.
- `FAQ.md` — краткая теория, разбор заданий и различий постановки с PDF.
- `task*.png` — рисунки, которые нужны для сборки отчёта.
- `requirements.txt` — зависимости Python.

Расчёт из корня проекта: `python lab1/lab1.py`.
Сборка на Mac из корня: `bash build_pdf.sh 1`; из каталога лабы: `bash build.sh`.
Установка программ и шрифтов: [MAC_SETUP.md](../MAC_SETUP.md).

Перед защитой прочитайте разделы 4 и 5 [FAQ.md](FAQ.md): имеющееся решение
использует $f(t)=t^2$ в задании 2 и нормальную производную сверху
в задании 3. Эти постановки отличаются от буквальной записи методички.
