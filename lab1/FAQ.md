# Лаба 1. Метод конечных разностей

## Определения и базовая теория

Основа — теоретические разделы 1.1–1.2 [instructions.pdf](instructions.pdf).
Ниже определения для устного ответа; применение к заданиям — далее.

### Математическая модель и производные

| Термин | Что означает |
|---|---|
| Математическая модель | Уравнения и условия, описывающие выбранные свойства физической системы |
| Скалярное поле $U$ | Одно числовое значение в каждой точке пространства; например температура или потенциал |
| Производная $dU/dx$ | Локальная скорость изменения функции по аргументу |
| Вторая производная $d^2U/dx^2$ | Скорость изменения первой производной; характеризует кривизну графика |
| Частная производная $\partial U/\partial x$ | Изменение функции по $x$ при фиксированных остальных независимых переменных |
| Дифференциальное уравнение | Связь неизвестной функции с её производными |
| Обыкновенное ДУ (ОДУ) | Неизвестная функция зависит от одного независимого аргумента |
| ДУ в частных производных | Неизвестная функция зависит от нескольких аргументов: например $U(x,y)$ или $U(x,t)$ |
| Порядок ДУ | Наивысший порядок производной, входящей в уравнение |
| Линейное ДУ | Функция и её производные входят линейно; нет их произведений, квадратов и нелинейных функций от них |
| Однородное линейное ДУ | Уравнение $\mathcal L U=0$; при правой части $f\ne0$ оно неоднородное |
| Источник | Заданный вклад в правую часть уравнения поля: например объёмное выделение тепла или плотность заряда с нужным коэффициентом |
| Стационарное поле | Поле, не меняющееся со временем; пространственная неоднородность при этом возможна |

**Лапласиан** — сумма вторых пространственных производных:

$$
\Delta U=\frac{\partial^2U}{\partial x^2}
+\frac{\partial^2U}{\partial y^2}
+\frac{\partial^2U}{\partial z^2}.
$$

В плоской задаче остаются только первые два слагаемых. Здесь $\Delta$ —
оператор; в записи погрешности $\Delta U$ ниже тот же символ имеет другой смысл.
Уравнения Пуассона, Лапласа, теплопроводности и Гельмгольца сопоставлены
в разделе 2. **Диффузия** — выравнивание неоднородной концентрации из-за
случайного движения; **теплопроводность** — перенос энергии, связанный
с неоднородностью температуры.

### Постановка задачи и численный метод

| Термин | Что означает |
|---|---|
| Начальные условия | Значения искомой функции и нужных производных в начальный момент/начальной точке |
| Задача Коши | Найти решение ДУ, удовлетворяющее заданным начальным условиям |
| Граничные условия | Ограничения на функцию или её производные на границе области |
| Краевая задача | ДУ внутри области вместе с условиями на её границе |
| Условие Дирихле | Задано значение функции на границе |
| Условие Неймана | Задана производная по нормали — направлению, перпендикулярному границе |
| Сетка и узел | Набор выбранных точек области и отдельная точка этого набора |
| Шаг сетки $h$ | Расстояние между соседними узлами равномерной сетки |
| Метод конечных разностей | Замена производных разностями значений в узлах и решение полученных алгебраических уравнений |
| Разностная схема | Совокупность этих уравнений, включая дискретные начальные/граничные условия |
| Шаблон «крест» | Центральный узел и его соседи по координатным направлениям; в 2D — пять узлов |
| Порядок аппроксимации $p$ | Ошибка замены уравнения имеет порядок $O(h^p)$ при достаточной гладкости решения |
| Разреженная матрица | Матрица, у которой большая часть элементов равна нулю |

Три этапа МКР из методички: **построить сетку → заменить производные
разностями и учесть условия → решить алгебраическую задачу**.
Плюсы — простота на регулярных областях и широкий круг задач;
минусы — неудобство сложных границ и быстрый рост числа неизвестных
при измельчении многомерной сетки. При уменьшении шага вдвое число узлов
в 2D примерно учетверяется.

Для механической интерпретации: **скорость** $v=dx/dt$,
**ускорение** $a=dv/dt$, второй закон Ньютона $ma=\sum F$.
Линейное сопротивление $F_{\text{сопр}}=-\alpha v$ направлено против
движения относительно среды. Знак ускорения сам по себе не определяет
ускорение или замедление: модуль скорости растёт при $va>0$ и падает при $va<0$.

## 1. Что делали и в чём идея метода?

Заменили производные разностями значений на сетке. Для задач Коши считали
следующий узел по предыдущим; для двумерной краевой задачи решали систему
линейных уравнений. Точное решение, где оно известно, служит проверкой.

Шаг $h$ — расстояние между узлами. Формулы следуют из ряда Тейлора:

$$
U'(x_i)\approx\frac{U_{i+1}-U_i}{h}\quad[O(h)],\qquad
U''(x_i)\approx\frac{U_{i+1}-2U_i+U_{i-1}}{h^2}\quad[O(h^2)].
$$

Центральная первая разность $(U_{i+1}-U_{i-1})/(2h)$ имеет порядок $O(h^2)$.
При уменьшении $h$ ошибка аппроксимации обычно падает, но расчёты дорожают,
а при слишком малом шаге заметны ошибки округления. **Аппроксимация** —
точность замены уравнения; **устойчивость** — контроль роста возмущений;
**сходимость** — приближение численного решения к точному при $h\to0$.
Одна точная формула производной ещё не гарантирует точность всей схемы:
важны начальные и граничные условия.

## 2. Какие уравнения из методички нужно различать?

В двумерном случае $\Delta U=U_{xx}+U_{yy}$ — оператор Лапласа.

| Уравнение | Смысл |
|---|---|
| $\Delta U=f$ — Пуассона | Стационарное поле с источниками |
| $\Delta U=0$ — Лапласа | Стационарное поле без источников в области |
| $\partial_tU=a^2\Delta U$ | Диффузия или теплопроводность |
| $\Delta U+cU=0$ — Гельмгольца | Пространственная часть гармонических процессов |

**Начальные условия** задаются в начальный момент; **граничные** — на краю
области. Дирихле задаёт $U$, Нейман — нормальную производную
$\partial U/\partial n$. Задача Коши для ОДУ второго порядка требует двух
начальных условий, например $U(0)$ и $U'(0)$.

## 3. Задание 1: что решали и откуда рекуррентная формула?

$$
AU''=B,\quad U(0)=C,\quad U'(0)=D;\qquad
A=2,\ B=3,\ C=1,\ D=3{,}14.
$$

Здесь $C$ — заданная константа, а не электрическая ёмкость.
Из разностного уравнения получаем:

$$
U_0=C,\quad U_1=C+Dh,\quad
U_{i+1}=2U_i-U_{i-1}+\frac BA h^2.
$$

Дважды интегрируя исходное уравнение, получаем точное решение:

$$
U(x)=C+Dx+\frac{B}{2A}x^2=1+3{,}14x+0{,}75x^2.
$$

$U$ — искомая величина поля; $U'$ — скорость её изменения по координате,
$U''$ — кривизна. Если аргумент трактовать как время, а $U$ как положение,
это движение с постоянным ускорением $B/A=1{,}5$.
Производные: $U'=3{,}14+1{,}5x$, $U''=1{,}5$.

**Почему есть ошибка даже для параболы?** В $U_1=C+Dh$ пропущена поправка
$Bh^2/(2A)$. Поэтому $U_i-U(x_i)=-iBh^2/(2A)$: ошибка накапливается.
На нашей сетке $h=0{,}02$, 50 узлов, последний $x=0{,}98$;
максимальная абсолютная ошибка $0{,}0147$, относительная — $0{,}3064\%$.
Для включения обоих концов 50 интервалов потребовался бы 51 узел.

## 4. Задание 2: уравнение, движение и важное различие с PDF

**В PDF записано $f(x)=x^2$, но существующий отчёт и код используют
$f(t)=t^2$. Это разные модели; на защите нужно явно назвать принятую
постановку и согласовать её с преподавателем.** Код сейчас решает:

$$
mx''+x'=t^2,\quad m=0{,}5,\quad x(0)=1,\quad x'(0)=0{,}5.
$$

Это второй закон Ньютона с силой $t^2$ и линейным сопротивлением $-x'$
(коэффициент сопротивления в выбранных единицах равен 1).
Прямая разность для $x'$ и центральная для $x''$ дают:

$$
x_0=1,\quad x_1=1+0{,}5h,\qquad
x_{i+1}=\frac{(2m+h)x_i-mx_{i-1}+h^2t_i^2}{m+h}.
$$

Для аналитического решения вводим $v=x'$: $0{,}5v'+v=t^2$.
С учётом начальных условий:

$$
x(t)=1+\frac{t^3}{3}-\frac{t^2}{2}+\frac t2,\quad
v=t^2-t+0{,}5=(t-0{,}5)^2+0{,}25>0,\quad a=2t-1.
$$

Тело всё время движется вперёд: до $t=0{,}5$ замедляется, затем ускоряется.
Минимум скорости — $0{,}25$ при $t=0{,}5$; там ускорение равно нулю.
В коде 80 узлов, $h=0{,}0125$, последний $t=0{,}9875$;
максимальная относительная ошибка около $0{,}2783\%$.
Для буквальной модели PDF было бы $\dot x=v$, $\dot v=(x^2-v)/m$;
приведённое полиномиальное решение к ней не относится.

## 5. Задание 3: двумерная задача и границы

Решено $U_{xx}+U_{yy}=1$ в квадрате $[0,1]^2$:
снизу и слева $U=1$; справа $U_x=0{,}5$, сверху **$U_y=0{,}5$**.
В PDF сверху написано $U_x(x,1)=0{,}5$; в отчёте принята нормальная
производная $U_y$. Это уточнение меняет постановку и требует пояснения.

Внутри области применяется пятиточечный шаблон «крест»:

$$
\frac{U_{i+1,j}+U_{i-1,j}+U_{i,j+1}+U_{i,j-1}-4U_{i,j}}{h^2}=1.
$$

На правой и верхней сторонах используются односторонние производные:
$(U_{N,j}-U_{N-1,j})/h=0{,}5$ и
$(U_{i,N}-U_{i,N-1})/h=0{,}5$.
В верхнем правом углу берётся среднее этих двух уравнений.
Внутренний шаблон имеет порядок $O(h^2)$, границы — $O(h)$;
объявлять всю схему схемой второго порядка нельзя.

Сетка: 40 интервалов, $h=0{,}025$, 41×41 узел.
После исключения известных нижней и левой сторон остаётся 1600 неизвестных.
Получаем разреженную систему $A\mathbf u=\mathbf b$: в каждой строке
лишь несколько ненулевых коэффициентов. Поверхность показывает высоту
$U(x,y)$, линии уровня соединяют точки одинакового $U$.
Результаты: $\min U\approx0{,}9804$, $\max U\approx1{,}3921$,
$U(0{,}5,0{,}5)\approx1{,}0271$. Точного решения здесь не использовали.

## 6. Что уметь объяснить в коде?

- `task1()` и `task2()`: сетка → два начальных узла → рекурсия → сравнение с точным решением.
- Ошибки: $\Delta=|u-u_{\text{точн}}|$, $\varepsilon=\Delta/|u_{\text{точн}}|\cdot100\%$; при нулевом знаменателе относительная ошибка не определена.
- `np.gradient()` в задании 2 оценивает скорость; ускорение вычисляется из уравнения $(t^2-v)/m$.
- `index(i,j)` переводит узел в номер неизвестной; `add_term()` переносит известные значения вправо.
- `lil_matrix` удобна для заполнения, `tocsr()` — для вычислений, `spsolve()` решает разреженную систему.
- В массиве `solution[j,i]` первый индекс соответствует $y$, второй — $x$.
