# Лабораторная работа № 3 — вариант 4

Общая установка и сборка на MacBook: [MAC_SETUP.md](../MAC_SETUP.md).
Краткая подготовка к устной сдаче: [FAQ.md](FAQ.md).

Тема: переходные и резонансные процессы в электрических цепях.
Параметры: R = 50 Ом, L = 180 мГн, C = 5 мкФ, U₀ = 10 В.

## Структура

- `lab3.pdf` — готовый отчёт.
- `lab3.tex` — исходник LaTeX, Times New Roman, 12 пт, интервал 1,5.
- `lab3.py` — расчёты всех семи заданий и построение графиков.
- `FAQ.md` — теория, контрольные вопросы, объяснение результатов для устной сдачи.
- `requirements.txt` — зависимости Python.
- `build.ps1`, `build.sh` — сборка PDF в PowerShell и Bash.
- `figures/` — семь рисунков в PDF и PNG.
- `results/` — численные данные в CSV, итоговые параметры в `summary.json`,
  автоматически создаваемые LaTeX-таблицы и `values.tex`.
- `build/` — служебные файлы сборки и проверки, не нужны для сдачи.
- `instructions.pdf`, `theory.pdf`, `LR3.pdf` — предоставленные материалы.

## Расчёты

Требуется Python 3.10 или новее. Из каталога `lab3`:

```powershell
python -m pip install -r requirements.txt
python lab3.py
```

На macOS обычно используется `python3` вместо `python`.
Скрипт можно запускать из любого каталога: пути определяются по расположению
`lab3.py`. Все расчёты ведутся в СИ. Скрипт обновляет `figures/` и `results/`.

Свободное движение решается методом DOP853 и сравнивается с аналитическим
решением. Период определяется по событиям положительных максимумов заряда.
Проверяется энергетический баланс. Частоты половинной мощности находятся
по линейной интерполяции дискретной частотной кривой.

## Сборка PDF

Нужны XeLaTeX (MiKTeX, TeX Live или MacTeX), шрифты Times New Roman и Consolas.
В кодовых вставках используется Consolas, основной текст набран Times New Roman.
Из каталога `lab3` на Windows:

```powershell
.\build.ps1
```

На macOS/Linux:

```bash
bash build.sh
```

При установленном PowerShell на macOS также можно выполнить:

```bash
pwsh -File ./build.ps1
```

XeLaTeX должен быть доступен в PATH. PowerShell-скрипт на Windows дополнительно
ищет MiKTeX в стандартной пользовательской папке установки.
Оба скрипта переносят конфликтующие служебные файлы из каталога исходников
в `build/previous-root/`, запускают XeLaTeX дважды, проверяют оглавление
и ссылки, затем обновляют `lab3.pdf`. В настройках LaTeX-редактора
также используйте каталог вывода `build`.

Для изменения расчётных параметров отредактируйте константы в начале
`lab3.py`, повторите расчёты и сборку. Текст отчёта подготовлен для варианта 4:
при переходе к другому варианту потребуется также обновить исходные данные
и пояснения в `lab3.tex`.
