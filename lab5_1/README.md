Готовый отчёт: [lab5.pdf](lab5.pdf), исходник: [lab5.tex](lab5.tex).

## Что лежит в папке

- `app-example/` — копия предоставленного приложения с исходными материалами.
- `screenshots/` — исходные снимки настоящих окон; `*_screen.png` содержит
  область электронограммы, `*_window.png` — окно с параметрами.
- `figures/` — снимки, собранные рядом, и графики обработки в PDF и PNG.
- `results/statistics_input.csv` — ручной перенос 20 строк экранной таблицы.
- `results/statistics.csv` — восстановленные целые счётчики и доли $k_j/k$.
- `results/measured_radii.csv` — отсчёты по изображениям и их масштабы.
- `results/voltage.csv`, `structure.csv`, `summary.json` — результаты расчётов.
- `results/capture_manifest.json` — параметры пусков, времена и SHA-256 снимков.
- `results/statistics_provenance.json` — связь перенесённой таблицы с её снимком.
- `lab5.py` — обработка результатов, без генерации электронов.
- `tools/` — автоматизация получения снимков на Windows и проверка PDF.
- `build.ps1`, `build.sh` — сборка отчёта в два прохода XeLaTeX.
- `tasks.pdf`, `theory.pdf`, `app-controlling.pdf` — условия и теория.

## Как запустить приложение и повторить опыт на Windows

Откройте `app-example/difraction.exe`. Ответы на входные вопросы:
**Б, Г, А, Г, Б, А, Б, В, В**.

1. Выберите **«Железо (Fe)»**. Через **«Вид → Масштаб → ×4»** задайте
   масштаб до пуска. Изменение масштаба очищает изображение.
2. Для накопления задайте напряжение и количество электронов,
   выключите «Добавить» и нажмите **«Пуск с добавлением»**.
   Повторите девять сочетаний из таблицы выше.
3. Для изменения темпа сначала завершите или остановите пуск,
   передвиньте регулятор и начните новый. При выключенном «Добавить»
   новая серия очищает старую. Конкретные точки каждый раз случайны.
4. Для статистики нажмите **«Одиночный пуск»**, задайте 40 кВ,
   1000 электронов и шаг 50. После пуска сохраните график и вкладку
   **«Статистика»**. Шаг 50 даёт 20 отсчётов — столько хранит график программы.
5. Для второго упражнения получите шесть электронограмм при напряжениях
   из задания, измерьте второе и третье кольца по линейке.
6. Для третьего упражнения при 30 кВ измерьте первые пять колец.
   Не путайте радиус с диаметром и номер кольца с порядком дифракции.

Готовые снимки всех этих серий уже сохранены в `screenshots/`.

## Как выполнялась обработка

Малое деление линейки — 1 мм. На сохранённых снимках при ×4 это около
5,43 пикселя. `lab5.py` выделяет тёмные метки, исключает синюю линейку
и находит положения колец в радиальной гистограмме. Расчётные радиусы
кристалла при поиске пиков не используются.
Отсчёт ведётся по малым делениям: между соседними подписанными
крупными рисками находятся десять таких делений.

Для отчёта отсчёты округлены до 0,1 мм; порядок точности чтения принят
около 0,2 мм. Это ориентир растрового отсчёта, не калиброванный
доверительный интервал. Полные числа в CSV нужны для воспроизводимости.
Количество тёмных пикселей не считается количеством электронов.

Встроенный статистический график показывает $k_1/k_0$, $k_3/k_0$,
$k_4/k_0$. По заданию нужны $k_1/k$ и $k_2/k$, где $k$ не включает центр.
Поэтому в отчёте есть и исходный снимок, и правильный пересчёт таблицы.
Целые счётчики восстановлены из округлённых долей $k_j/k_0$;
при наших $k_0\leq1000$ они определяются однозначно.

Графика $R(X)$ в приложении нет: он построен отдельно по измеренным
радиусам. Приложение использует приближённое масштабирование
$R\propto V^{-1/2}$, поэтому данные не полностью воспроизводят
релятивистскую зависимость из задания. В отчёте показаны фактические
отсчёты и этот предел виртуального опыта.

## Пересчитать сохранённые данные

Из корня проекта:

```powershell
python -m pip install -r lab5_1/requirements.txt
python lab5_1/lab5.py
python lab5_1/lab5.py --verify
```

На Mac замените `python` на `python3` либо используйте активированное
виртуальное окружение. Для обработки готовых снимков Windows не нужна.

Скрипт проверяет SHA-256 приложения, снимков и перенесённой таблицы.
Несовпадение означает, что исходные данные изменились: его нужно
разобрать до пересчёта, а не обходить проверку.

## Пересобрать PDF

Требуются **XeLaTeX** и **Times New Roman**. Дополнительный шрифт кода
этому отчёту не нужен. Установка MacTeX и шрифтов описана в
[MAC_SETUP.md](../MAC_SETUP.md).

Windows, из корня проекта:

```powershell
.\lab5_1\build.ps1
```

Mac/Linux, из корня проекта:

```bash
bash lab5_1/build.sh
```

Для сборки уже подготовленного отчёта Python не нужен. Переносите
`lab5.tex`, `figures/`, `screenshots/`, `results/` и скрипт сборки вместе.
Сам `difraction.exe` — Windows-приложение; на Mac готовые данные можно
обрабатывать и собирать PDF отдельно от его запуска.

## Служебные скрипты

`python lab5_1/tools/capture_example.py` повторяет пуски в отдельном
экземпляре приложения и сохраняет снимки. Запуск возможен на Windows.
После нового случайного опыта нужно заново перенести таблицу статистики
в CSV и обновить `statistics_provenance.json` после проверки переноса.

`tools/capture_speeds.py` повторяет только проверку темпа.
`tools/verify_report.py` проверяет итоговый PDF и создаёт превью в `build/`;
для него дополнительно нужна библиотека PyMuPDF.
